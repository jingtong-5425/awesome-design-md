# 风格图集文件

[打开完整中文图集](../风格图集.md)

- png/：84 张独立示意图，1600 × 1000，可直接预览或引用。
- svg/：84 张对应的矢量图，可无损放大。
- contact-sheets/：10 张分类拼图，方便快速比较。
- overview.png：12 套风格的精选总览。
- profiles.json：84 份规范中提取的颜色、字体和展示参数，以及源版本与说明。
- render.mjs：PNG/SVG 再生成脚本，需 Node.js 与 sharp；浏览与引用图集无需安装任何东西。

图集属于规范演绎，不是官网截图或官方设计资产；字体为系统近似，具体设计仍以各 DESIGN.md 为准。统一虚构内容用于比较，没有接入真实产品功能。
